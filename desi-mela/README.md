# 🎡 Desi Mela 3D: Ring Toss & Balloon Shooting Game

A lightweight, hyper-realistic Indian Mela game containing **Ring Toss (Chhalla Feko)** and **Balloon Shooting (BB Rifle)** stalls with nostalgic 3D physics, synthesized pop/wood clack sound effects, and festive carnival visuals!

---

## 📁 Directory Location
This game has been created on your Desktop at:
`C:/Users/USER/Desktop/Desi_Mela_Game/`

---

## 🚀 How to Play / Preview Immediately in Browser (Web App)

1. Open `C:/Users/USER/Desktop/Desi_Mela_Game/index.html` in any web browser (Chrome, Edge, Safari, Firefox).
2. **Ring Toss Mode:** Swipe UP with your mouse or finger to throw gold rings onto Cadbury Dairy Milk, Thums Up bottles, Parle-G, Stainless Steel Tiffins, Auto-Rickshaws, and ₹500 notes!
3. **Balloon Shoot Mode:** Tap/click directly on balloons to shoot them with synthetic pop sound effects and particle explosions!

## 📱 How to Wrap into Native Android APK & iOS App Store App

We have configured **Capacitor** inside this project so you can export to Android & iOS in 5 minutes!

### Step 1: Install Capacitor CLI (In Terminal inside `Desi_Mela_Game` folder)
```bash
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
```

### Step 2: Add Android & iOS Platforms
```bash
npx cap add android
npx cap add ios
```

### Step 3: Build & Open Native Android / iOS Studio
```bash
npx cap copy
npx cap open android   # Opens Android Studio to export APK for Google Play Store
npx cap open ios       # Opens Xcode to export IPA for Apple App Store
```
