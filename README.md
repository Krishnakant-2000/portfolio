# 🌐 Krishnakant Bhardwaj — Personal Developer Portfolio Website

An interactive, modern portfolio website showcasing **Full-Stack Mobile Engineering (React Native / Expo), Supabase / Firebase Backends, Real-time Analytics, and 3D Web Games**.

---

## ✨ Features Included
* **Hero Section:** Animated typing text effect, quick stats, and call-to-action buttons.
* **About & Career Timeline:** B.Tech CS (2022) to 4+ years of professional full-stack development experience.
* **Featured Projects Showcase:**
  1. **AmaPlayer App (`New_UI`):** React Native mobile app with 21 sports, 3D Trading Cards, and Deep Insights.
  2. **Desi Mela 3D Game (`Desi_Mela_Game`):** 8 HTML5 Canvas carnival games with coin economy and physics.
* **Technical Skills Matrix:** Interactive tech stack cards.
* **Responsive Design:** Mobile, tablet, and desktop layout built with Tailwind CSS & Glassmorphism.

---

## 📸 Adding Your Own Photo
To use your real photo:
1. Copy your photo into `assets/profile.jpg` inside this folder.
2. Refresh `index.html` in your browser!

## 🚀 How to Publish Live on GitHub Pages (100% Free)

1. Create a new repository on GitHub named: **`krishnakant-2000.github.io`**
2. Open terminal in this folder and run:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/Krishnakant-2000/krishnakant-2000.github.io.git
   git push -u origin main
   ```
3. Your portfolio will automatically be live at: **`https://krishnakant-2000.github.io`**!
